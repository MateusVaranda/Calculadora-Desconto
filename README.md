# Calculadora-Desconto

🚀 Mais um projeto concluído! | Calculadora de Desconto

Estou desenvolvendo minhas habilidades em Desenvolvimento Web, dessa vez criei uma Calculadora de Desconto, utilizando HTML, CSS e JavaScript.

O objetivo do projeto foi desenvolver uma aplicação simples e funcional, capaz de calcular automaticamente o percentual de desconto, o valor descontado e o preço final do produto.

💻 Tecnologias utilizadas:

HTML5 – Estruturação da aplicação.

CSS3 – Estilização e organização visual.

JavaScript – Lógica de programação, cálculos, validações e manipulação do DOM.

📚 Principais conceitos praticados:

Manipulação de elementos HTML com JavaScript.

Captura e conversão de valores dos inputs.

Funções e estruturas condicionais.

Cálculos matemáticos e porcentagem.

Eventos de clique (addEventListener).

Exibição dinâmica de resultados na página.
